# Green Corridor 🚑

Green Corridor is a smart emergency transport management platform designed for:

* Organ Transport
* Patient Transfer
* Blood Transport
* Body Transfer
* Medical Equipment Transport

## Features

### Hospital Dashboard

* Create Mission
* Manage Ambulances
* Manage Drivers
* Mission Center
* Analytics

### Driver Dashboard

* View Assigned Missions
* Start Journey
* Live Tracking (Planned)

### Mission Center

* Incoming Missions
* Outgoing Missions
* Mission Status Tracking

### Super Admin

* Hospital Management
* Ambulance Management
* Driver Management
* Approval System

## Future Scope

* Supabase Authentication
* Live GPS Tracking
* Real-Time Notifications
* Green Corridor Route Assistance
* Citizen Alerts
* Analytics Dashboard

Built using Flutter.
